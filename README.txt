JUMIL — Sitio web rediseñado

ARCHIVOS
- index.html       Página principal
- styles.css       Diseño responsive
- script.js        Navegación, animaciones y formulario
- privacy.html     Plantilla de política de privacidad

PUBLICACIÓN
1. Subir los 4 archivos a la raíz del hosting.
2. Configurar el dominio para que apunte a index.html.
3. La web no requiere compilación ni dependencias.

FORMULARIO
La versión entregada no almacena datos en un servidor. Prepara la consulta y permite enviarla por:
- WhatsApp: 927 800 578
- Correo: contacto@jumil.com

Si se desea captación automática de leads, debe conectarse el formulario a un backend, CRM o servicio de formularios.

ANTES DE PUBLICAR DEFINITIVAMENTE
- Verificar nombres, cargos y datos de contacto.
- Completar RUC, domicilio y datos legales en privacy.html.
- Sustituir la política de privacidad provisional por la versión validada legalmente.
- Añadir favicon y logotipo oficial si se dispone del archivo corporativo.

ACTUALIZACIÓN: IMÁGENES DINÁMICAS
- Hero con 3 imágenes corporativas en transición automática.
- Tarjetas de servicios con fotografía y efecto hover.
- Galería dinámica “Operación en movimiento” con reproducción automática, controles y navegación por puntos.
- Respeta prefers-reduced-motion para accesibilidad.
- Las fotografías se cargan desde Unsplash mediante HTTPS; para producción corporativa definitiva se recomienda sustituirlas por fotografías propias de JUMIL y mantener los mismos nombres/clases.
